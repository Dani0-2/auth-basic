# Auth-basica
Api para probar el funcionamiento de JWT

## Requisitos
Node.js v18+

## Instalacion
git clone https://github.com/Dani0-2/auth-basic.git
cd auth-basica

## Uso
```bash
node index.js
```

El script a traves de peticiones consigue mostrar el uso de JWT para el proceso de autenticacion en una app.
